# 解答用紙メーカー
問題番号と模範解答を入力すると、解答欄を自動でレイアウトし、解答用紙と模範解答を同時に作るWebツールである。ExcelとPDFでの出力、印刷ができる。

**公開URL: https://answersheet-maker.vercel.app/**

## 作った理由
- 教員の友人の悩みから起案した
- テストのたびに一から作り、調整するのが地味に大変
- 学校現場で導入されているツールはなさそう

## 考えたこと

### 配点を解答欄に書かない
自動採点で答案をスキャンするとき、解答欄の中の配点が手書きの数字と混ざって読み取りに不具合が出るとの意見があったため、用紙には配点を出さない。配点は、入力画面の合計チェックにだけ使う。

### 入力内容を外に出さない
テスト前の問題や解答は一応機密情報であるため、処理はブラウザ内で行い、保存は`localStorage`で行う。外部との通信は、`index.html`のCSPで禁止している。

### 解答欄の大きさは、模範解答の長さから決める
欄の大きさを毎回指定しなくて済むよう、模範解答の文字数から「記号」「語句」「記述」を判定し、自動でマスの大きさを決める。
必要なときには、マスの大きさ（字数×行数）を指定することもできる。

### 問題の入れ替え、追加、削除の操作をやりやすく
設問の並べ替えはドラッグで行える。入力欄の間は、Enterキーや矢印キーで移動でき、マウスに持ち替えなくても入力を続けられる。

キー操作は、使いながら3回に分けて直した。
1. 数値欄で上下キーを押すと値が増減してしまうため、上下キーでは隣の行へ移動するようにした。
2. 模範解答の欄は複数行を書くため、Enterを改行にし、末尾の空行でEnterを押したときだけ下へ移動する形にした。
3. 2の方式でも、改行を続けたいときに意図せず移動する場面があった。そこで、模範解答の欄ではEnterも下キーも移動させず、改行だけにした。2で入れた処理は不要になったので外した。

### 見た目
- 解答用紙の見出しは、答案をめくりながら探しやすいよう、タイトル→組・番号・氏名→得点の順に並べ、右端（縦書きは下端）にそろえる。
- 用紙の下に1行に満たない隙間が残るときは、大問の見出しの行に振り分けて、解答欄が下の余白まで届くようにする（マスの大きさは変えない）。
- 新しい設問は、直前の設問の設定（大きさ・マス目）を引き継ぐ。同じ形の設問が続くことが多いため。

### 保存データの形式を変えても、古いデータを読めるようにする
設問ごとの大きさとマス目の指定を変えたとき、旧形式の保存データは読み込み時に新しい形へ変換するようにした。作りかけのテストが、更新で壊れないようにするため。

### 機能を絞り、細かい調整はExcelに任せる
Excelで出力すれば個人でのカスタマイズが可能なため、過度に機能を多くしすぎず、シンプルな設計にした。

### 画面・印刷・Excelを同じレイアウトから描く
レイアウトの計算は`src/lib/layout.ts`の1か所だけで行い、できたセルの一覧から、プレビュー・印刷・Excelをすべて描く。表示ごとに計算すると、画面と印刷でずれるため。

### 壊れにくくするためのテスト
レイアウトは条件の組み合わせが多いため、単体テストに加えて、乱数（固定シード）で作った設問を大量に流し込む「fuzzテスト」で、セルが重ならない、ページからはみ出さない、といった性質を確かめている。

## できること
- テスト情報の設定: タイトル、満点、用紙（A4/B4/B5）、縦・横、横書き・縦書き、組・番号・氏名欄
- 設問の入力: 大問・小問、種類、模範解答、配点、マス目
- 解答欄の自動サイズ（記号・語句・記述）、字数を指定したマス目、複数ページ
- プレビュー（解答用紙・模範解答）。パソコンの画面では入力と左右に並べて表示し、境目をドラッグで動かせる
- Excel出力（解答用紙・模範解答の2シート）、PDF出力、印刷
- 入力内容の自動保存（`localStorage`）

## 使用技術
React / TypeScript / Vite / Mantine / ExcelJS / Vitest

## 構成
```
src/
├─ App.tsx            画面を組み立てる
├─ hooks/             入力内容の保持・自動保存
├─ components/        TopBar / MetaForm / QuestionTable / QuestionRow / Preview / Sheet
└─ lib/
   ├─ constants.ts    係数・用紙サイズ・余白・フォント（調整はここ）
   ├─ layout.ts       レイアウト計算（解答欄の大きさ、折り返し、ページ分割、縦書き変換）
   ├─ excel.ts        Excel出力
   ├─ sample.ts       サンプル
   └─ *.test.ts       テスト
```

## 既知の制限
- Excelのフォントは「游ゴシック」を指定している（無い環境ではExcel側で代わりのフォントになる）
- 実際のExcel・プリンターでの見た目は、環境によって差が出ることがある
- 「PDFで保存」のPDFは、用紙を300dpiの画像にしたもので、文字の選択・検索はできない。ブラウザによっては作れないことがあり、その場合は「印刷」から「PDFに保存」を選ぶ
