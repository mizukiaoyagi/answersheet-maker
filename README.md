# 解答用紙メーカー

中学・高校の先生向けの Web ツールです。問題番号・模範解答・配点を入力すると、答えの長さに合った解答欄を自動でレイアウトし、**解答用紙**と**模範解答**を同時に作ります。Excel・印刷・PDF に対応しています。

入力内容（テスト前は機密）は**サーバーに送りません**。すべてブラウザの中で処理します。外部への通信（API・アクセス解析・外部フォント・CDN）はなく、ビルド結果は静的な HTML 1 枚です。ネットを切っても使えます。

## できること

- テスト情報（タイトル・満点・用紙 A4/B4・縦横・横書き/縦書き・組/番号/氏名欄）
- 設問の入力（大問・小問・種類・模範解答・配点・マス目の字数）、ドラッグで並べ替え
- 解答欄の自動サイズ（記号・語句・記述）、字数を指定したマス目、複数ページ
- プレビュー（解答用紙・模範解答）、配点の合計チェック
- Excel 出力（解答用紙・模範解答の 2 シート）、印刷・PDF
- 入力内容は localStorage に自動保存

## 開発

```bash
pnpm install
pnpm dev      # 開発サーバー
pnpm test     # 単体テスト
pnpm build    # 型チェック + 単一 HTML を dist/index.html に出力
```

`dist/index.html` は、ダブルクリックで開いても（`file://`）動きます。

## 構成

```
src/
├─ App.tsx            画面を組み立てる
├─ hooks/             入力内容の保持・自動保存
├─ components/        TopBar / MetaForm / QuestionTable / QuestionRow / Preview / Sheet
└─ lib/
   ├─ constants.ts    係数・用紙サイズ・余白・フォント（調整はここ）
   ├─ layout.ts       レイアウト計算（解答欄の大きさ、折り返し、ページ分割、縦書き変換）
   ├─ excel.ts        Excel 出力
   ├─ sample.ts       サンプル（理科・社会・国語）
   └─ *.test.ts       単体テスト
```

プレビュー・印刷・Excel は、`layout.ts` が作る同じセルの一覧から描くので、レイアウトがそろいます。

## 公開（Vercel）

静的ファイルだけなので、Vercel の「Vite」プリセットでそのまま公開できます。設定は `vercel.json` にあります。

1. GitHub にこのリポジトリを置く
2. Vercel で「Add New → Project」から、そのリポジトリを選ぶ
3. 設定は変えずに Deploy

`index.html` の CSP（`connect-src 'none'` など）で、ブラウザからの外部通信を禁止しています。

## 注意

- Excel のフォントは「游ゴシック」を指定しています（無い環境では Excel 側で代わりのフォントになります）。
- 実際の Excel・プリンターでの見た目は、お使いの環境で確認してください。
